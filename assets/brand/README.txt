simba logo kit

Colours
  Teal      #0B5D55   (main)
  Ink       #13302C   (word on light)
  Cream     #F7F1E3   (lion on the app icon)
  Mint      #7FD3C6   (lion on dark)
Typeface: Lexend Bold (the word "simba"), Lexend Regular (tagline). Text is converted to outlines, so no font is needed to open the files.

Files
  simba-logo-horizontal(.svg / -dark)  lion + simba + tagline: slides, report cover, README
  simba-logo-stacked(.svg / -dark)     lion above simba: splash screen, poster
  simba-wordmark.svg                   the word only
  simba-lion-teal / -white / -mint     the lion symbol only
  simba-app-icon.svg / .ico            app icon (the .ico holds 16-256 px, for Windows and Electron)
  png/                                 ready-made PNGs (app icon 16-1024 px, logos at 2x)

Use SVG wherever possible (it stays sharp at any size). Use PNG for PowerPoint/Word if SVG won't insert.
Keep clear space around the logo of at least the height of the letter "s".
